# aiml_loan_approoval_system
we have created a bank loan approval system using basic python , aiml and some simple tools. the data set contains about 45k entries and our models gives about 94% accuracy

we have used 3 basic algorithms for this 
1. logisitc regression
2. random forest
3. xgboost

the important graphs are mentioned in the ppt section and other important points like f1 score etc are also mentioned.

xg boost has given us the best accuracy so far
